## Таблицы
1. users - пользователи(справочник):
    - full_name - Фио
    - gender - пол
    - age - возраст
    - weight - вес
    - height - рост
    - physical_activity_level - уровень физической активности

2. dishes - блюда(справочник):
    - dish - название блюда
    - calories - его калорийность
    - proteins - белки
    - fats - жиры
    - carbohydrates - углеводы

3. meal - приемы пищи(справочник):
    - meal - прием пищи

4. dishes_meal - блюдо/прием пищи(промежут, одно блюдо может быть и обедом и ужином):
    - id_dishes - id_блюдо
    - id_meal - id_прием пищи

5. menu_plans - меню пользователя по датам(факт?, один пользователь может создать несколько меню):
    - id_user - id_пользователя
    - daily_calories - норма калорий в день
    - start_date - дата начала недели
    - end_date - дата конца недели

6. menu_items - блюда, расписанные по дням(факт):
    - id_menu_plans - id_плана меню
    - day - день
    - id_meal - id_приема пищи
    - id_dishes - id_блюда
